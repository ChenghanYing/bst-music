# BST Music

A C project that uses a Binary Search Tree (BST) to organize, search, and manipulate music playlists.

## Features

- Insert songs into a BST
- Search for songs efficiently
- Delete songs while maintaining BST properties
- In-order and pre-order traversal
- Generate playlists
- Reverse song order
- Harmonize songs by shifting pitch and timing

## Technologies

- C
- Binary Search Tree
- Dynamic Memory Management
- Recursion

## What I Learned

This project strengthened my understanding of binary search trees, recursive algorithms, pointer manipulation, and dynamic memory management in C. I also gained experience designing modular programs and implementing complex data structures from scratch.
